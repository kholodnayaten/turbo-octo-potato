# Использование ChatGPT в Visual Studio Code

Ниже — самый простой способ «запустить» меня в VS Code: это делается через расширение, которое подключается к вашему API‑ключу OpenAI.

## Вариант 1: расширение, работающее с API‑ключом OpenAI

1. Установите **Visual Studio Code**.
2. Откройте **Extensions** (`Ctrl+Shift+X`).
3. Установите расширение, которое умеет работать с OpenAI (например, расширение с названием **ChatGPT**, **OpenAI**, **Continue** и т.п.).
4. В настройках расширения укажите ваш **OpenAI API key**.
5. Откройте панель чата расширения и начните диалог.

## Вариант 2: GitHub Copilot Chat

Если у вас есть подписка **GitHub Copilot**, можно:

1. Установить расширения **GitHub Copilot** и **GitHub Copilot Chat**.
2. Войти в GitHub в VS Code.
3. Открыть панель Copilot Chat и общаться там.

## Проверка

Если чат открывается и отвечает, значит всё настроено правильно.
